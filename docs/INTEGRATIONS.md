# Integrations

P0 has **no enabled external integration**. Import uses user-selected local JSON; export downloads a local text file.
No GitHub API access, ChatGPT/Gemini/Claude access, MCP endpoint, or cloud sync is wired into the app.

P1 candidate connections require explicit least-privilege authorization, clear scopes, expiry, export previews, and threat modeling. Do not claim connected MCP or AI memory capabilities before verification.
