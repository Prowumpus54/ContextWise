# Test matrix

| Check | Command / method | Status |
|---|---|---|
| Syntax | `npm run check` | Not executed |
| Unit tests (schema, zoom, scope) | `npm test` | Not executed |
| Full verification | `npm run verify` | Not executed |
| Browser smoke | `npm run dev`, open localhost | Not executed |
| Security tests | future local encryption/backup cases | Not implemented |
| Hosting and deployed endpoint | future explicit approval | Not deployed |

Do not mark a check as passed based solely on writing a CI workflow.
