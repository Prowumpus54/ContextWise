# Release checklist

- [ ] Automated tests and syntax checks pass
- [ ] Desktop + mobile browser smoke passes
- [ ] Import rejects malformed or oversized input
- [ ] Project scope cannot leak through exports or inspector
- [ ] No sensitive sample content or secrets in repository
- [ ] User-visible status accurately describes lack of encryption
- [ ] Security assessment completed before persistent vault or public private-data usage
- [ ] Accessibility and keyboard interactions checked
- [ ] Build/commit identity and deployment URL recorded
